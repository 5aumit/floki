Floki TUI — One Dark theme samples

Five directions for the Textual TUI, all built on the Atom One Dark palette. Welcome panels use the real _BANNER_LINES ASCII from console_ui.py (same glyphs + magenta→blue hexes as production; other themes only remap those line colors). Leave notes in each comment box (saved in this browser via localStorage).
