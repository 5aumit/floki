2 · Tool → verb map

Tool Verb shown Rationale
list_experiments_tool listing Browsing experiment catalog
list_runs_tool scanning Walking runs in an experiment
count_runs_per_experiment_tool counting Aggregate run counts
get_run_metrics_tool fetching Pulling metric values
get_run_params_tool inspecting Reading run params
find_best_runs_by_metric_tool ranking Top-k by metric
check_experiment_generalization_tool checking Train/test generalization check
unknown / no tool / agent-only turn thinking Default fallback
formatter phase (optional) formatting After tools finish, while BlockResponse builds

Behavior: start at thinking → on each tool call replace the verb in place (keep the pulse) → when a later tool fires, swap again → unknown tool name → thinking. Dim tool name optional (shown in demo for clarity; can hide in ship).
